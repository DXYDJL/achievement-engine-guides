# Achievement Engine 社区攻略使用指南

这里收录玩家分享的成就攻略。你可以在《成就引擎》中浏览、预览和下载已发布的攻略；这些操作无需登录 GitHub。想要投稿时，才需要使用 GitHub 账号登录并授权。

## 浏览和下载攻略

1. 在软件中打开“社区攻略”，选择游戏或搜索攻略名称、作者。
2. 打开攻略详情，先预览内容和版本信息。
3. 选择下载并导入。攻略会作为本地攻略版本保存，之后可以按自己的需要继续编辑。

社区中同一款游戏可以有多个独立攻略系列。它们可能采用不同的章节安排、成就顺序或攻略思路；下载前请确认攻略标题和简介符合你的需要。

## 投稿攻略

投稿前，请在软件中选择投稿方式：

- **更新攻略**：选择从社区下载后编辑过的攻略，向对应的社区攻略系列提交改进。审核发布后会成为该系列的新版本。
- **新建攻略**：选择本地新建的攻略，建立一个独立的社区攻略系列。同一款游戏已有其他社区攻略时，仍可以创建不同结构或不同思路的攻略。

投稿时请检查攻略标题、版本号、简介和内容许可，并确认攻略正文、图片及其他素材均有权分享。单份攻略包不超过 500 MB，单个文件不超过 100 MB。

首次投稿需要按软件提示登录 GitHub 并查看授权范围。授权后即可提交攻略；提交并不代表立即发布，攻略需要通过自动检查和维护者审核。你可以在软件的“投稿记录”中查看进度并刷新状态。审核合并并正式发布后，其他用户才能在社区中浏览和下载该版本。
