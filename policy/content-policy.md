# 自动内容接收规则

投稿须通过以下技术检查，并经维护者审核后才能合并发布：

- GitHub 登录身份与清单作者账号一致，作者已声明拥有必要发布权并同意所选许可证。
- 清单、攻略正文和成就绑定符合 JSON Schema；攻略必须属于当前游戏。
- HTML 只允许校验器列出的标签、属性、样式和 HTTPS 外链；脚本、事件属性、远程图片及不支持的内容会被拒绝。
- 图片必须能安全解码，并由服务端重新编码、清除元数据；资源路径、大小、数量和 SHA-256 必须与包内清单一致。
- 服务端接收时和发布前都会重新校验完整攻略包；任何失败都会阻止合并或发布。

这些规则能验证结构、身份声明和可检测的安全条件，不能自动证明攻略事实正确、投稿者实际拥有素材版权，或识别所有隐私、广告和不当表达。投稿者声明承担相应责任；发现问题时维护者仍可关闭 PR、撤下发布版本并处理举报。
